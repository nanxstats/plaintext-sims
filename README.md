Computational experiments for *The Plaintext Statistician* exploring
plaintext (Git-first) versus mixed (email/Office) workflows.
A stylized SimPy discrete-event model contrasts the two.

## Quickstart

```bash
uv sync
uv run python -m plaintext_sims.run
```

Outputs land in `results/` as CSV tables, PNG plots, and a short text summary.
Adjust parameters in `config/experiments.yaml` and re-run to explore
alternative assumptions. Defaults: 10,000 replications per arm;
1,000 bootstrap resamples per metric.

## Experiment design

- **Scope:** Single Phase III study delivering SAP -> ADaM -> TLF -> QC -> reporting.
- **Resources:** Shared pools (defaults) statisticians=3, programmers=4, QC=2.
- **Workflow arms:** Plaintext (Git branches/PRs, automated checks, decision records) vs mixed (email/Office, meeting-driven, partial versioning).
- **Tasks:** clarify requirements -> ADaM programming -> TLF programming -> QC/reconcile -> reporting.
- **Random elements:** log-normal task times; miscommunication driving rework or latent defects; late defects discovered in QC; lead unavailability triggers handover penalty.
- **Key parameters (plaintext vs mixed) from `config/experiments.yaml`:**
  - Base task means (days): clarify 18 vs 15; ADaM 28 vs 24; TLF 26 vs 22; QC 18 vs 15; reporting 12 vs 10
  - Duration sigma: 0.35 vs 0.30
  - Miscommunication prob: 0.12 vs 0.25
  - Late defect prob: 0.05 vs 0.12
  - Early detection prob: 0.65 vs 0.25
  - Handover penalty: 4 vs 9 days; lead unavailability prob: 0.06 vs 0.12
  - Rework scale/latent fix time: 0.6 & 5 days vs 0.9 & 7 days

## Implementation

- **Engine:** SimPy processes per task type with shared resource pools; log-normal durations sampled per task.
- **Rework logic:** Miscommunication can trigger immediate rework (early detection) or latent defects resolved in QC; late defects also drawn independently.
- **Handover:** Tasks requiring the lead incur a stochastic delay when the lead is unavailable, scaled by `handover_penalty_days`.
- **Configuration:** All tunables in `config/experiments.yaml`; dataclass-backed in `src/plaintext_sims/experiment.py`.
- **Plots:** plotnine boxplots per metric and a trade-off scatterplot (mean total time vs. mean late defects).

## Analysis outputs

Generated by `uv run python -m plaintext_sims.run`:

- `simpy_results.csv`: per-replication metrics
- `simpy_summary.csv`: means/medians/SDs and quantiles by condition
- `simpy_bootstrap_effects.csv`: bootstrap mean differences (plaintext vs mixed)
- Plots: `*_boxplot.png`, `tradeoff_time_vs_late_defects.png`
- Narrative: `simpy_summary.txt`

## Reproducing or extending

- Tweak task times, probabilities, resource counts, seeds in `config/experiments.yaml`.
- For alternative metrics or visualizations, edit `experiment.py`, `metrics.py`, or `plot.py`.
- Re-run the pipeline with `uv run python -m plaintext_sims.run`.
